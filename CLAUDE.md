# TeamUp

PWA для школьников Алматы (14–18 лет): поиск тиммейтов на хакатоны, олимпиады и студпроекты. Финальная стадия перед запуском, прод: team-up-web.netlify.app.

## Стек
- React 18 + TypeScript + Vite + Tailwind, TanStack Query, react-hook-form + zod, react-router 6
- Firebase: Auth, Firestore, Storage, Cloud Functions (`functions/`), FCM пуши
- PWA через vite-plugin-pwa, деплой на Netlify; Firebase project `teamup-6a054`
- Языки интерфейса: RU / KZ / EN (`src/i18n`). Любой новый текст добавляй во все три.

## Команды
- `npm run dev` – локально
- `npm run lint`, `npm run build` – обязательно прогоняй после изменений
- `npm test` – юнит-тесты (vitest)
- `npm run test:rules` – тесты Firestore/Storage rules на эмуляторе (Java уже стоит)
- Деплой правил/функций: `firebase deploy --only firestore:rules` / `--only functions`

## Как со мной работать
- Пиши по-русски, коротко и по делу. Без длинных тире (—), используй обычный дефис или запятую.
- Сразу давай конкретное решение и делай его, без длинной диагностики и лишних объяснений.
- Не добавляй то, о чём не просили. Если видишь проблему рядом, просто упомяни одной строкой.
- Перед крупными изменениями (архитектура, схема Firestore, правила безопасности) коротко опиши план и подожди ок.

## Правила проекта
- Безопасность важнее удобства: пользователи несовершеннолетние. Любое изменение данных проверяй против `firestore.rules`, при правке правил добавляй/обновляй тесты в `tests/rules`.
- Контакты видны только участникам команды. Создание проектов, заявки и посты требуют подтверждённой почты (проверяется в rules).
- Push-токены хранятся в `users/{uid}/private/notifications`.
- Не трогай `.env` и не коммить секреты.
- Известная проблема: после деплоя service worker отдаёт старый бандл. Для проверки: инкогнито или unregister SW + очистка данных сайта.
